## Production API Routing Verification

### Frontend → Backend API Calls:

1. **Login Flow**
   - Frontend: POST to `${API_BASE_URL}/auth/login`
   - Production resolves to: `https://flowx-traffic.onrender.com/api/auth/login` ✅

2. **OAuth Google Flow**
   - Frontend: GET to `${API_BASE_URL}/auth/google/initiate`
   - Callback: `pages/oauth-callback.html` (fixed to use config.js)
   - Production backend: `https://flowx-traffic.onrender.com/api/auth/google/callback` ✅

3. **OAuth Apple Flow**
   - Frontend: GET to `${API_BASE_URL}/auth/apple/initiate`
   - Callback: `pages/oauth-callback.html` (fixed to use config.js)

   - Frontend: Loads from `/js/config.js`
   - Determines API base URL based on hostname
